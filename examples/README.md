# Pixel TZZ Pro 示例内容

本目录中的内容用于开发和验收，不是完整玩法数据包。

- `pixel-tzz-base-datapack`：健康的 2A–3A 综合验收夹具，包含初始化、准备、最小任务时间线、玩家终端、裁剪历史、注册函数、页面预览和一个统一主题。
- `pixel-tzz-base-resourcepack`：页面样例使用的最小资源包；只提供本项目翻译，纹理和声音优先复用 Minecraft 原版资产。
- `pixel-tzz-required-asset-fixture`：默认不要安装。它依赖基础数据包，用于验证“必需客户端资产缺失”时的内置安全错误页。
- `pixel-tzz-3a-pressure-datapack`：默认不要安装。它以更高优先级覆盖基础包的少量资源，用于十项长个人字段、十二条玩家历史和超长中文独占选项的收口压力验收。

正常验收先启用基础数据包和基础资源包。只有执行对应异常或压力测试时，才额外启用所需覆盖夹具。

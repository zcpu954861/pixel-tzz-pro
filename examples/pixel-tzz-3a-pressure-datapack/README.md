# Pixel TZZ Pro 3A 人工压力验收覆盖包

这是叠加在 `pixel-tzz-base-datapack` 之上的一次性验收包，只用于可丢弃的 `3A V1` 世界。
它不会改动正式协议，也不应随正式游戏发布。

覆盖包提供三组难以通过正常流程自然构造的边界数据：

- 将玩家历史切换为逐事件显示，并注册 `压力记录 01` 至 `压力记录 12`；
- 将“个人信息”入口临时指向双独立滚动区页面，并投影十项长中文授权数据；
- 保留三个猎人出生点的机器值，但把显示名称与说明替换为超长中文。

启用后必须重置验收局并重新走到 `pixel_tzz:acceptance/main_branch`，再执行：

```mcfunction
/function pixel_tzz:acceptance_3a/pressure/record_twelve
```

PlayerB 打开“过去事件”应看到 12 条记录并默认选中 `压力记录 12`；打开“个人信息”应看到左右
两块可分别滚动的长字段区域。

测试完成后禁用本覆盖包、执行 `/reload`，再重置验收局，即可恢复基础数据包的任务汇总历史、
普通个人信息页与短出生点名称。

## 持久化保护

世界状态文件位置：

```text
<world>/data/pixel-tzz-pro/world_state.dat
```

保护规则：

1. 当前 Schema 正常读取时按服务端权威状态工作；
2. 可读取但 Schema 或字段不兼容时，保留原始 NBT 并进入只读；
3. 外层 NBT、压缩或 I/O 读取失败时，在覆盖前复制到：

```text
<world>/data/pixel-tzz-pro/recovery/world_state-load-failed-<timestamp>.dat
```

4. 本次服务器会话随后取消新建状态的脏标记，原文件保持不变；
5. 修复或恢复原文件后重启服务器，才重新尝试正常加载。

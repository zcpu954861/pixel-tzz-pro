# 第二里程碑 2B：数据驱动页面框架实施与验收计划

状态：**核心实现已完成，等待用户实机验收**  
最后整理：2026-07-27  
模组版本：`0.1.0`  
Minecraft：`26.2`  
网络协议：`5`

详细格式见 [`DATA-PACK-UI-2B.md`](DATA-PACK-UI-2B.md)。

## 当前实现快照

- 页面和主题已经接入严格候选编译、不可变 generation、协议 v5 下发和客户端缓存；
- 生产布局、组件渲染、预览器、主题、动画及资源预检已经落地；
- 所有 Button 都必须提供页面内唯一的稳定 `id`，缺失时页面候选编译失败；
- Repeat 模板当前不支持 FieldInput；
- `clip_progress` 当前固定从左向右揭示；
- `scale` 围绕节点进行几何缩放，不触发布局重排或字号重新测量；
- EditBox 的标签和提示可以使用主题字体，玩家输入的正文仍使用原版字体，以保持光标、选择和裁剪宽度一致；
- Local、Flow 和 Registered 页面动作均由预览器截获并显示请求信封，不向服务端发送，也不修改权威状态；
- 当前基础示例包含 `31` 个文件和 `23` 项 Pixel TZZ 定义；
- 视觉、声音、键盘操作、资源异常手感及 32/64 人性能仍需用户在真实客户端中验收。

## 1. 里程碑目标

2B 要证明：

1. 页面和主题可以像 2A 的其他定义一样由数据包注册；
2. 不可信页面在服务端通过严格 Schema、类型、引用和复杂度校验；
3. 客户端只渲染服务端下发的已验证页面；
4. 一套生产布局、绑定和组件实现同时服务真实页面与开发预览；
5. 不依赖尚未确定的地图、任务或主线即可完整验收；
6. 2B 不修改任何权威游戏状态。

## 3. 实施顺序

以下顺序是边界，不代表必须创建同名类：

1. 页面/主题模型与严格编译器；
2. 纯 Java 测量、布局及诊断；
3. 绑定上下文和增量表达式；
4. 客户端基础组件与复用按钮；
5. 页面缓存及按需同步；
6. 资源预检和安全错误页；
7. 动画、音效、减少动态效果和讲述人；
8. Repeat 虚拟化；
9. 管理员预览器；
10. 示例内容、自动检查和实机验收。

每一步优先复用 Minecraft/Fabric 原生能力，不引入新的第三方依赖。

## 4. 自动检查矩阵

### 4.1 发现和 ID

- 页面和主题路径正确映射命名空间 ID；
- 高优先级同路径资源完整覆盖；
- 无命名空间、非法路径和重复候选被拒绝；
- 页面必须引用存在的游戏；
- 页面引用存在的主题；
- 页面、主题和 2A 定义一起原子发布。

### 4.2 严格 JSON

- 未知键；
- 重复键；
- 尾随内容；
- 错误根类型；
- 缺少必填字段；
- 错误枚举；
- 错误数字类型；
- 非有限数；
- 负尺寸；
- 越界颜色、动画、声音和断点；
- 超过单文件字符数或 JSON 深度。

### 4.3 组件树

- 根节点非空；
- 节点类型存在；
- 节点 ID 合法且唯一；
- 叶子节点拒绝 children；
- 单子节点容器拒绝多个 children；
- 深度、节点总数和单容器子节点上限生效；
- JSON Pointer 精确指向错误字段。

### 4.4 布局

- Content、Fixed、Fill、Percent、Weight 的测量结果确定；
- Weight 只在允许容器内使用；
- Min/Max 冲突被拒绝；
- Row/Column 主轴和交叉轴对齐正确；
- Grid 轨道、间距和 span 正确；
- Flow 在边界宽度稳定换行；
- Overlay 锚点和裁剪正确；
- Scroll 单轴滚动及焦点入视口；
- Compact、Standard、Wide 阈值边界无一像素抖动；
- 相同输入重复布局得到相同结果；
- 溢出产生有界诊断，不产生负尺寸或异常。

### 4.5 绑定和表达式

- 固定 binding path 对应正确类型；
- 不存在、未公开或任意路径被拒绝；
- Field、Flow Field、UI 和 Repeat Item 作用域隔离；
- 比较运算类型匹配；
- 数值运算拒绝文本；
- All、Any、Not 和 Exists 语义正确；
- 表达式深度和节点数上限生效；
- 依赖未变化时不重复求值无关节点。

### 4.6 主题

- 默认主题可独立渲染；
- 数据包主题按固定顺序覆盖；
- 不存在的令牌或样式被拒绝；
- 令牌循环被拒绝；
- 状态样式不能移除禁用原因；
- 节点行内覆盖只接受白名单属性；
- 页面主题可以被多个游戏复用。

### 4.7 组件

- Text 静态、翻译、绑定、拼接、换行和省略；
- Image contain、cover、stretch、alt 与回退；
- Button 正常、悬停、焦点、按下和禁用；
- 返回按钮本体和命中区域保持固定，只有两侧箭头响应真实鼠标悬停并平滑收回；
- Divider 和 Spacer 不干扰焦点；
- Progress 分母为零安全；
- PlayerHead 缺皮肤使用原版回退；
- Repeat 使用稳定 key，单项更新不重建整页；
- Repeat 超过阈值启用虚拟化；
- Repeat 在 Compact 使用单列、Standard/Wide 使用双列网格时，按完整行计算可见窗口和跨列占位；
- FieldInput presentation 与字段类型严格匹配。

### 4.8 动画与音效

- 支持的属性、缓动和关键帧正确；
- 关键帧顺序、首尾和上限生效；
- 动画只改变表现，不改变逻辑状态；
- 减少动态效果直接到达安全最终态；
- ESC、控制台、页面目录按 root/push/pop 的层级方向切换，同级替换使用 replace；
- 系统转场期间锁定输入，结束后才替换 Screen；返回保留上一级目录状态；
- 原版“屏幕效果强度”为零时，系统转场只保留短淡化；
- 讲述人不朗读动画帧；
- 缺少可选声音不阻断页面；
- 默认按钮悬停静音；特殊页面显式启用悬停音时仍受限流；
- 音量、音高、延迟和引用数上限生效。

### 4.9 页面同步和缓存

- 客户端只接受兼容格式；
- generation、页面 ID 和 SHA-256 组成稳定缓存键；
- 相同页面不重复下发；
- 新 generation 不替换冻结页面实例；
- 未引用旧缓存按 LRU 回收；
- 页面关闭后释放订阅；
- 过期或错误 hash 页面被拒绝并进入安全页；
- 单包和缓存总量上限生效。

### 4.10 资源预检

- 自动收集页面和主题资产；
- 可选字体、图片、皮肤、翻译和声音按规则回退；
- 必需缺失资产阻止业务页面显示；
- 安全错误页不依赖数据包资源；
- 诊断包含类型、ID、页面、generation 和 JSON Pointer；
- 明细截断后总数准确；
- 同一缺失资产不会每帧或每次布局重复上报；
- 资产报告不能完成流程或改变状态。

### 4.11 动作和信任边界

- Local 动作只改变页面局部状态；
- Flow 与 Registered 在 2B 中只显示请求，不执行；
- 页面不存在的节点或动作不能伪造；
- generation/revision 不匹配请求被拒绝；
- 重复请求序号被拒绝；
- 不可见或禁用按钮请求被拒绝；
- 客户端不能提交“已完成”“我是猎人”等最终状态；
- 高风险确认令牌结构预留但 2B 不提交真实操作。

### 4.12 世界状态不变

2B 全套预览、重载、错误页面和动作模拟前后：

- 世界阶段不变；
- 主持人不变；
- 身份、队伍、生存状态不变；
- 字段和准备状态不变；
- 2A 世界状态文件的 SHA-256 不变；
- `/reload` 只发布定义 generation。

## 5. 性能验收

### 5.1 常规

- 32 人列表滚动、焦点和状态更新无可感知冻结；
- 空闲页面不每 Tick 全量重算；
- 单个玩家在线状态变化只更新依赖该值的节点；
- 页面关闭后不继续求值、播放声音或订阅数据。

### 5.2 压力

- 64 人 Repeat；
- 同屏多种 FieldInput；
- 最大合法页面节点数；
- 最大合法表达式；
- 最大合法动画和诊断数量；
- 连续切换三种响应视口；
- 多次有效、无效和恢复 `/reload`；
- 页面缓存到达页数或字节上限。

压力测试应记录：

- 页面编译耗时；
- 首次布局耗时；
- 单帧可见节点数；
- Repeat 实际实例化项数；
- 缓存大小；
- 诊断总数与截断数。

不为漂亮指标牺牲正确状态；性能不足时先减少非关键动画和不可见项工作。

## 6. 客户端实机验收计划

实现完成后，使用 `run/client` 的独立测试快照，不修改 HMCL 原世界。

### 6.1 进入预览器

1. 启动开发客户端并进入测试世界；
2. 打开 ESC 中的“全员逃走中”；
3. 管理员控制台出现“页面预览器”入口；
4. 普通玩家不获得管理员预览入口；
5. 预览器按游戏列出当前 generation 页面。

### 6.2 视觉与布局

- 默认主题延续已经确认的“电视节目控制台”；
- 按钮、色板、状态卡和信息层级保持统一；
- Compact、Standard、Wide 均无重叠、截断或无法点击；
- Grid、Flow、Overlay 和 Scroll 能在真实 GUI 缩放下工作；
- 调试边界准确包围节点；
- 溢出节点能定位到 ID 和 JSON Pointer。

### 6.3 交互

- 鼠标、Tab、方向键、Enter 和 Esc；
- 返回按钮箭头只在鼠标悬停时出现；
- 禁用按钮显示并朗读原因；
- Scroll 中焦点自动进入可见范围；
- FieldInput 可以编辑本地预览值；
- 按钮显示将发送的请求，但不修改游戏状态。

### 6.4 动画和声音

- 页面出现、悬停、选择、成功和错误节奏自然；
- ESC → 控制台 → 页面目录 → 数据包页面的前进、返回和关闭转场方向连续；
- 动画连续，不出现生硬跳变；
- 音效不刺耳、不刷屏；
- 关闭 UI 音量后静音；
- 减少动态效果后直接显示最终状态；
- 动画和音效不延迟按钮权限或错误。

### 6.5 资源异常

- 删除可选测试纹理后使用占位图且页面可操作；
- 删除可选声音后静默继续；
- 删除必需测试纹理后进入内置安全错误页；
- 错误页可重试、查看诊断和退出；
- 恢复资源并重载后能正常预览；
- 主持人诊断能看到对应玩家和缺失资产。

### 6.6 长列表

- 模拟 0、1、32、64 人；
- 列表项目身份、在线和状态表达明确；
- 64 人滚动不卡住客户端；
- 列表变化不重置无关项目的焦点和滚动位置。

### 6.7 重载和缓存

- 打开页面后执行 `/reload`；
- 当前冻结预览可以继续显示旧 generation；
- 手动选择“重新加载最新定义”后切换新 generation；
- 无效候选保留上一代并显示诊断；
- 修复后发布下一代；
- 世界状态保持不变。

## 7. 验收证据格式

最终收口时必须记录：

- `foundationSelfCheck` 结果；
- 2B 页面自检结果；
- `clean check build` 结果；
- 有效/无效/恢复 generation 序列；
- 测试世界状态文件前后 SHA-256；
- 示例数据包和资源包文件数量及逐路径哈希；
- 32/64 人预览器性能摘要；
- 用户实机确认的视觉、交互、动画、音效和资源异常结果；
- 未提交、未推送状态。

静态检查不能代替真实客户端中的布局、动画、声音、键盘和资源回退验收。

## 8. 明确不验收

2B 不以以下结果作为通过条件，也不能提前实现：

- 玩家完成真实初始化；
- 玩家真实准备；
- 主持人指定猎人；
- 任何真实身份、队伍或生存状态变化；
- 正式高风险二次确认执行；
- 主持人 BossBar；
- 正式任务、地图、倒计时、捕获、复活或运镜；
- 多游戏活动配置选择。

## 9. 完成定义

2B 只有同时满足以下条件才收口：

1. 文档、实现和示例一致；
2. 自动检查全部通过；
3. 独立服务端的有效/无效/恢复重载安全；
4. 真实开发客户端完成预览器验收；
5. 缺少可选和必需资产的行为正确；
6. 32/64 人列表性能有界；
7. 页面动作不能修改权威状态；
8. 用户明确确认 UI、交互、动画和声音通过；
9. 保持未提交、未推送，等待用户决定 Git 操作。

当前尚未完成第 4、5、6、8 项对应的用户实机验收，因此即使核心实现与自动检查通过，也不能将 2B 标记为最终通过。

完成后先停止，不自动进入流程执行层。
